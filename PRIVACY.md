# EasyUniTrack privacy policy

_Last updated: 13 October 2026_

EasyUniTrack is a planner for students made by PandaDev Studio. It's built so that your information stays with you.

## The short version

EasyUniTrack doesn't collect, sell or share your information, and nothing you enter in the app is ever sent anywhere. There are no accounts, no sign-in, no advertising and no analytics or tracking. The only time the GitHub version goes online is to check for updates, explained under [Internet use](#internet-use).

## What the app stores, and where

Everything you enter (tasks, subjects, calendar items, job applications, money records and your settings) is saved in a file on your own computer:

- Microsoft Store version: in the app's own data folder that Windows manages for you. If you used the GitHub version on the same computer before, the Store version keeps using that existing `%APPDATA%\EasyUniTrack` folder instead
- Version from GitHub: `%APPDATA%\EasyUniTrack`

The app also keeps an automatic daily backup copy in the same folder. None of this ever leaves your computer unless you choose to move it, for example by downloading a backup file and copying it somewhere yourself.

Only people who can sign in to your Windows account can open these files, the same as your other documents.

## Internet use

- **Microsoft Store version:** the app doesn't connect to the internet. The Microsoft Store handles updates.
- **Version from GitHub:** to tell you about new versions, the app asks GitHub for the latest release each time you open it, and when you press **Check now**. This request contains no information about you or your data. Like any website, GitHub can see your computer's IP address when it's contacted; see [GitHub's privacy statement](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement). You can turn this off in **Settings → Updates**.
- Links you click, such as a job advertisement link you saved, open in your own web browser.

## Notifications and Start with Windows

Reminder notifications are created on your computer from your own tasks. "Start with Windows" only opens the app when you sign in. Both can be turned off in **Settings**.

## Removing your information

You can delete any item in the app at any time. Uninstalling the Microsoft Store version removes the data it created. If you used the GitHub version on the same computer before, the existing `%APPDATA%\EasyUniTrack` folder is kept after uninstalling; delete it yourself to remove that data too. Before uninstalling, use **Settings → Your data → Download backup** if you want to keep a copy. For the GitHub version, delete the `%APPDATA%\EasyUniTrack` folder to remove everything.

## Children

EasyUniTrack doesn't collect information from anyone, including children.

## Changes to this policy

If this policy changes, the new version will be posted here with a new date.
